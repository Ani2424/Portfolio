# Anirban Basak — Portfolio

Static personal portfolio built with plain HTML and CSS.

## Files

- `index.html` — page content and sections
- `styles.css` — responsive styling

## Customize

1. Update the biography, education, project descriptions, and skills in `index.html`.
2. The contact link uses `imanibasak0@gmail.com`; update it in `index.html` if needed.
3. Add real links for your resume, project demos, GitHub profile, and LinkedIn profile.

## GitHub Pages

GitHub Pages is configured to deploy from the root (`/`) of the `main` branch. Changes committed to `main` automatically trigger a site deployment. HTTPS is enforced on the default GitHub domain.
