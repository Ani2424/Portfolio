# Anirban Basak — Portfolio

Static personal portfolio built with plain HTML and CSS.

## Files

- `index.html` — page content and sections
- `styles.css` — responsive styling

## Customize

1. Update the biography, education, project descriptions, and skills in `index.html`.
2. Replace `YOUR_EMAIL_HERE` in the contact link with your email address.
3. Add real links for your resume, project demos, GitHub profile, and LinkedIn profile.

## GitHub Pages

This repository is structured for GitHub Pages from the root of the `main` branch. After pushing it to GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
